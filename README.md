# lewies-grow-box

Automated indoor gardening.

An Arduino sketch (`lewies-grow-box.ino`) for a grow box controller from early 2017. It uses a Nokia 5110-style LCD (Adafruit PCD8544 library), a DS1307 real-time clock, and a keypad with a normal mode and a menu mode that returns to normal after 10 seconds. A photo of the v0.2 alpha build is in [doc/](doc/v0.2-alpha.jpg).

This was a short experiment and is not maintained.
